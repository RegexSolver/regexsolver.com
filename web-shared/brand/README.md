# Brand assets (canonical)

The RegexSolver lockup: two automaton-state circles (ink A `#2A3FD4`, ink B
`#D13E1E`) whose intersection lens is the overlap colour (`#6E2C6B`) — the
two-inks identity drawn as geometry — next to a "regexsolver" wordmark set in
Martian Mono (wdth 87.5, wght 700) converted to SVG paths.

This folder is the single source of truth for every frontend:

- `../src/brand.ts` — the lockup as raw SVG data, exported as
  `@regexsolver/web-shared/brand`. The website and console render it with
  thin `<Logo/>` components (`apps/com.regexsolver/src/components/Logo.tsx`,
  `apps/com.regexsolver.console/src/components/logo.tsx`) coloured by the
  identity's CSS tokens, so it adapts to dark mode.
- `logo-{light,dark}.svg` — full lockup with baked colours (docs header +
  footer, which load it via `<img>`)
- `mark-{light,dark}.svg` — the mark alone (avatar candidate)
- `favicon-mark.svg` — the mark on a square canvas with thickened strokes
  (7.5% of canvas ≈ 1.2px at 16px); source of the rasters below
- `favicons/` — rendered favicon set, copied into every app's `public/` by
  `../scripts/sync-brand.mjs` (wired as each app's `prebuild`; the copies are
  also committed so plain `dev` works)
- `og/og-{default,docs,console}.png` — the 1200x630 social share cards
  (`og:image`/`twitter:image`), one per frontend, generated by `gen_og.py`.
  `sync-brand.mjs` copies each app's variant to its `public/og-image.png`, so
  the URL in the app metadata is always `/og-image.png`. 1200x630 is the 1.91:1
  Facebook/LinkedIn/X all crop to; the PNGs are flattened to opaque RGB because
  some scrapers composite transparency to black.

## Regenerate

`.venv/`, `martian.ttf` and `jetbrains.ttf` are build inputs, not sources — they
are gitignored, so recreate them before regenerating anything.

```bash
cd apps/web-shared/brand
python3 -m venv .venv && .venv/bin/pip install fonttools
curl -sL -o martian.ttf "https://github.com/google/fonts/raw/main/ofl/martianmono/MartianMono%5Bwdth%2Cwght%5D.ttf"
.venv/bin/python gen_logo.py            # SVGs + ../src/brand.ts

# social share cards (gen_og.py also needs the mono face)
curl -sL -o jetbrains.ttf "https://github.com/google/fonts/raw/main/ofl/jetbrainsmono/JetBrainsMono%5Bwght%5D.ttf"
.venv/bin/python gen_og.py              # og/og-*.svg
for v in default docs console; do
  inkscape og/og-$v.svg -w 1200 -h 630 -o og/og-$v.png
  convert og/og-$v.png -background "#FBFAF7" -alpha remove -alpha off -strip \
    PNG24:og/og-$v.png
done

# favicon rasters (needs inkscape + imagemagick)
for s in 16 32 48 192 512 750; do
  inkscape favicon-mark.svg -w $s -h $s -o favicons/fav-$s.png
done
# apple-touch-icon gets an opaque paper background (iOS composites
# transparency as black): add <rect width="1600" height="1600"
# fill="#FBFAF7"/> as the first child, render at 180, then revert.
convert favicons/fav-16.png favicons/fav-32.png favicons/fav-48.png favicons/favicon.ico

node ../scripts/sync-brand.mjs          # propagate to the apps' public/
```
