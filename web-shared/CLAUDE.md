# web-shared — the site's brand, fonts and small shared modules (`@regexsolver/web-shared`)

Tiny raw-TypeScript package consumed by the site (`../site`) as a
`file:../web-shared` dependency (npm symlinks it; `moduleResolution: bundler`, so
the `.ts` sources are bundled directly — no build step). It comes from the m-lab
monorepo, where a console and a docs site shared it too; both are retired.

## Modules (exports map in package.json)
- `./analytics` — `initAnalytics(posthog, {token, apiHost, source, debug})`: PostHog,
  cookieless and anonymous (`memory` persistence, no person profiles, no exception
  capture or session recording), so there is no consent to ask and no cookie banner.
  `source` is registered as the `app` super property and the hostname-derived
  `environment` (`dev`/`prod`) as another. A `local` hostname (localhost / 127.0.0.1 /
  *.local) skips init: local dev never sends events. The site's privacy policy
  (`site/src/views/Privacy.tsx`) describes this; change the two together
- `./site-links` — `NAV_ITEMS` (header), `FOOTER_LINKS`, `COPYRIGHT`, and the
  `DOCS_URL`/`GITHUB_URL`/`CRATE_URL` they use. Website paths carry the trailing slash
- `./components/Logo` — the lockup renderer, colours through the identity tokens the
  site's `index.css` defines
- `./brand` — the lockup geometry `Logo` draws (generated, see `brand/`)

## brand/ (assets, not code)
`brand/` is the canonical home of every visual asset, generated by two Python scripts
and copied into the site's `public/` by `scripts/sync-brand.mjs` (the site's
`predev`/`prebuild`) — see `brand/README.md` for the regenerate flow.
- `gen_logo.py` → the lockup/mark SVGs, the favicon rasters, and `src/brand.ts`
- `gen_og.py` → `brand/og/og-default.png`, the 1200x630 share card, copied to
  `public/og-image.png` (the `og-docs`/`og-console` variants are unused leftovers)
Both scripts need a venv + `brand/martian.ttf` + `brand/jetbrains.ttf`, gitignored
build inputs; the generated SVG/PNG output is committed.

## fonts/ (assets, not code)
The committed copy of the site's three webfonts — Martian Mono (display), Instrument
Sans (body), JetBrains Mono (code). Nothing fetches them from Google, at build time or
at runtime.
- `scripts/fetch-fonts.mjs` regenerates the directory (run by hand). **All 14 subsets
  are kept, not just latin** — the demo renders arbitrary user-supplied regexes, so
  Cyrillic/Greek/Vietnamese input must still find a real face. `unicode-range` means a
  browser downloads only what a page uses.
- The woff2 filenames carry a content hash.
- `fonts.css` writes `url()`s root-absolute (`/fonts/…`): the rules get inlined into the
  stylesheet that imports them, so a relative path would resolve against the wrong base.
  `sync-brand.mjs` copies the woff2 into `site/public/fonts/` and writes
  `site/src/app/fonts.css`, this file with `NEXT_PUBLIC_BASE_PATH` in front of each
  `url()`, which the site's layout imports.
- `fonts/preload.ts` exports `FONT_PRELOAD`, the three latin faces worth a preload,
  generated because the hashed names would rot in hand-written code.

## scripts/indexnow.mjs (tooling)
The IndexNow ping the deploy workflow runs after a production deploy
(`node web-shared/scripts/indexnow.mjs https://regexsolver.com`): it fetches the live
`sitemap.xml` and submits its URLs so the engines implementing the protocol (Bing,
Yandex, Seznam, Naver — not Google) recrawl on a push.
- `INDEXNOW_KEY` must equal the name and contents of
  `site/public/7dfa2483f6057cb87aa0cbec916d71cb.txt` (unignored by a `!` line in
  `site/public/.gitignore`). Rotating the key = edit the constant, rename the file,
  rewrite its contents.
- Guards: the origin must be the prod origin; its `<key>.txt` must serve the key; the
  sitemap must be non-empty and list only URLs under that origin. GETs retry 3x/5s.
- `--dry-run` prints the payload and submits nothing.

## Hard constraints
- **No runtime imports except `react`.** `initAnalytics` takes the posthog instance as
  a parameter (typed structurally via `AnalyticsClient`) instead of importing
  posthog-js. React works because the site's bundler resolves it to its own copy; the
  dev-only `react` + `@types/react` in `devDependencies` (installed by the site's
  `predev`/`prebuild`) are there for tsc, not at runtime. Do NOT map react through
  tsconfig `paths`: Turbopack applies them at runtime.
- **Env vars stay in the site**: config (token, host) is passed in as arguments from
  `site/src/lib/posthog.ts`.
- **Tailwind**: `Logo`'s classes live outside the site's sources, so the site's
  `index.css` declares `@source "../node_modules/@regexsolver/web-shared/src"`.
- Code that touches `window`/`document` stays guarded: the static export evaluates
  these modules during prerendering.
